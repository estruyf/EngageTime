## 💡 What is EngageTime?

EngageTime is a platform designed to make events more engaging and interactive. Whether you're running a single-track community meetup or a large multi-day conference, EngageTime gives organizers and speakers the tools to connect with their audience in real time.

**Key features:**
- Live polls and Q&A
- Session feedback and ratings
- Multi-track schedule support
- Attendee engagement analytics
- Custom branding
- CSV exports
- Desktop application for live reactions, Q&A, etc...
